# GLOSSARY

| 詞 | 意思 |
|----|------|
| 格子 | 地圖上的一個正方形單位 |
| 地形 | 格子的類型 |
| 視野 | 以角色為中心的 13x13 格子 |
| 行動 | 角色花費現實時間執行的一件事 |
| 閒置 | 角色沒有進行中的行動 |
| AP | ActionPoint，隨現實時間累積的儲備，用來加速行動 |
| 加速 | 花費 AP 縮短進行中行動的剩餘時間 |
| 屬性 | 一類行動對應的能力 |
| 熟練度 | 屬性的累積值 |
| 材料 | 用於建造與製作的物品 |
| 工具 | 持有時提供效果的物品 |
| 食物 | 可以進食的物品 |
| 飽足 | 進食後持續一段時間的狀態，期間行動時間縮短 |
| 背包 | 角色隨身攜帶物品的空間 |
| 地面 | 每一格放置物品的公共空間 |
| 耐久度 | 建築或物品的剩餘壽命，以百分比表示 |
| 工地 | 建造中的建築 |
| 建築 | 已完成、提供效果的建造物 |
| 野生動物 | 依地形出現在格子上的動物 |
